   ├─ Payment Method (Card/Cash/UPI)

   └─ Form validates → API call sent

6. API PROCESSES ORDER
   ├─ frontend/js/api.js (placeOrder function)
   └─ POST to /api/place_order.php

7. SERVER SAVES TO DATABASE
   ├─ Lookup user by email
   ├─ Create order in "orders" table
   └─ Create items in "order_items" table

8. RESPONSE SENT TO FRONTEND
   └─ {success: true, orderId: "ORD-XXXXXX"}

   └─ Redirected to tracking page
