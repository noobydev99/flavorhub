## 📊 Database Tables

### Orders Table
Stores main order information with 14 columns:
- `id` - Database ID (Primary Key)
- `order_id` - Customer-facing order number (ORD-XXXXXX)
- `user_id` - Link to user who placed order
- `customer_name`, `customer_phone`, `customer_address` - Delivery details
- `payment_method` - How customer paid
- `special_instructions` - Any notes from customer
- `subtotal`, `tax`, `delivery_fee`, `total` - Cost breakdown
- `status` - Current order state
- `estimated_time` - Delivery estimate
- `created_at` - Timestamp

### Order Items Table
Stores individual items in each order:
- `id` - Database ID
- `order_id` - Reference to orders table
- `food_id` - Which item was ordered
- `name` - Item name (for record keeping)
- `unit_price` - Price per unit
- `quantity` - How many ordered
- `total_price` - quantity × unit_price
